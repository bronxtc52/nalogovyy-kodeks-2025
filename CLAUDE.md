# Инструкции для агента, работающего с этим репозиторием

Здесь лежит машинно-читаемый Налоговый кодекс РК. Если тебя спрашивают о налоговой
норме — отвечай по файлам этого репозитория, а не по памяти.

## Как искать

1. **Знаешь номер статьи** — открой файл напрямую: `code/ru/**/st-NNN.md`
   (быстрее всего `grep -rl "^article: \"190\"" code/ru`).
2. **Знаешь тему** — сначала [index.md](index.md): это полное дерево
   «часть → раздел → глава → статья» с заголовками всех 849 статей.
3. **Не знаешь ни того, ни другого** — полнотекстовый поиск:
   `grep -ril "счет-фактура" code/ru | head` или, если собран индекс,
   `python3 scripts/ask.py "<вопрос>" --dry-run` (нужен `dist/tax.sqlite`,
   собирается `python3 scripts/build_sqlite.py`).

Полный текст статьи лежит в самом файле — `data/chunks.jsonl` не читай целиком,
он для внешних RAG-систем и весит 10 МБ.

## Как отвечать

- **Всегда указывай статью и пункт**: «статья 190, пункт 3». Пункт адресуем
  якорем — `code/ru/.../st-190.md#p-3`.
- **Проверяй дату введения нормы**: поле `effective_from` во frontmatter.
  Кодекс действует с 01.01.2026, но у части статей срок другой, а поле
  `effective_note` описывает случаи, когда позже вводится только часть статьи.
- **Не пересказывай норму по памяти.** Если нужной статьи в репозитории нет —
  скажи об этом прямо, не достраивай ответ по общим знаниям о налогах.
- **Не давай налоговых консультаций.** Излагай, что написано в норме;
  оценку конкретной ситуации оставь человеку. Это неофициальная копия —
  см. [DISCLAIMER.md](DISCLAIMER.md).
- Перекрёстные ссылки статьи перечислены в `cross_references` — по ним удобно
  дотягивать связанные нормы, не перечитывая весь раздел.

## Если правишь корпус

Markdown в `code/ru/` — источник истины, но **править его руками нельзя**:
`text_sha256` во frontmatter перестанет сходиться и `scripts/validate.py` упадёт.
Правильный путь — поменять `scripts/build_corpus.py` и пересобрать:

```bash
python3 scripts/build_corpus.py && python3 scripts/build_chunks.py && python3 scripts/validate.py
```

Скрипты держим на стандартной библиотеке Python: CI гоняет их без `pip install`.
