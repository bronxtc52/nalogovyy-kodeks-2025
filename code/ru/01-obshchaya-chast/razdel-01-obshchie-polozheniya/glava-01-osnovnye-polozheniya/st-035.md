# Статья 35. Методологический совет по вопросам налогообложения

> [!info] Общая часть > Раздел 1. Общие положения > Глава 1. Основные положения > Параграф 3. Общие положения по налоговой политике
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=1160) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. В целях выработки предложений по устранению неясностей, неточностей и противоречий, которые могут возникнуть в ходе исполнения налоговых обязательств, создается Методологический совет по вопросам налогообложения.

<a id="p-2"></a>2. Положение о Методологическом совете по вопросам налогообложения и его состав утверждаются Премьер-Министром Республики Казахстан.
