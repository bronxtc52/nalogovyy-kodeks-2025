# Статья 31. Принцип единства налоговой системы

> [!info] Общая часть > Раздел 1. Общие положения > Глава 1. Основные положения > Параграф 2. Правовые основы налогообложения
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=1155) · обновлено 01.09.2024 · редакция 2026-01-01
