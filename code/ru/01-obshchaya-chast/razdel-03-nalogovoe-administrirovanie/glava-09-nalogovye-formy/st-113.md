# Статья 113. Налоговое заявление

> [!info] Общая часть > Раздел 3. Налоговое администрирование > Глава 9. Налоговые формы
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=149) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Налоговое заявление – документ налогоплательщика (налогового агента), представляемый в налоговый орган с целью реализации его прав и исполнения обязанностей в случаях, установленных настоящим Кодексом.

<a id="p-2"></a>2. Формы налоговых заявлений утверждаются уполномоченным органом.
