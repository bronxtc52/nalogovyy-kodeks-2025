# Статья 127. Упрощенный порядок возврата суммы превышения налога

> [!info] Общая часть > Раздел 3. Налоговое администрирование > Глава 10. Учет исполнения налогового обязательства, социального обязательства > Параграф 2. Возврат суммы превышения налога на добавленную стоимость
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=169) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Упрощенный порядок возврата суммы превышения налога заключается в осуществлении возврата суммы превышения налога с применением системы управления налоговыми рисками без проведения налоговой проверки.

<a id="p-2"></a>2. Упрощенный порядок возврата суммы превышения вправе применить плательщики налога:

1) состоящие на налоговом мониторинге, в течение календарного года совершавшие обороты по реализации, облагаемые по нулевой ставке;

2) у которых обороты по реализации, облагаемые по нулевой ставке, составляют не менее 50 процентов в общем облагаемом обороте по реализации за налоговый период.

<a id="p-3"></a>3. Сумма превышения налога подлежит возврату плательщикам налога, указанным в пункте 1 настоящей статьи, при одновременном соответствии следующим условиям:

1) отсутствия неисполненного уведомления на дату представления требования о возврате;

2) наличия подтвержденного к возврату по результатам налоговой проверки суммы превышения налога в течение двенадцати месяцев, предшествующих дате представления требования о возврате.

<a id="p-4"></a>4. Возврат плательщику налога суммы превышения налога в упрощенном порядке производится в течение пятнадцати рабочих дней, следующих за днем представления требования о возврате.
