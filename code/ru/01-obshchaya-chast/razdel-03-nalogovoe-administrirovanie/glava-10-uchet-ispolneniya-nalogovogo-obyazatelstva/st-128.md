# Статья 128. Порядок возврата суммы превышения налога по результатам тематической налоговой проверки

> [!info] Общая часть > Раздел 3. Налоговое администрирование > Глава 10. Учет исполнения налогового обязательства, социального обязательства > Параграф 2. Возврат суммы превышения налога на добавленную стоимость
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=170) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Сумма превышения налога, не возвращенная в упрощенном порядке плательщику налога, осуществляющему реализацию товаров, выполнение работ, оказание услуг, облагаемых по нулевой ставке, подлежит возврату по результатам тематической налоговой проверки.

<a id="p-2"></a>2. Тематическая налоговая проверка проводится в соответствии с главой 15 настоящего Кодекса.

<a id="p-3"></a>3. Налоговый орган по результатам тематической налоговой проверки составляет заключение к акту налоговой проверки при получении ответа

на запрос налогового органа о результатах проверки, осуществленной

в отношении покупателя продуктов переработки налоговой службой государства – члена ЕАЭС.

Заключение к акту налоговой проверки составляется и вручается налогоплательщику не позднее пяти рабочих дней со дня получения ответа на запрос.

<a id="p-4"></a>4. При возврате суммы превышения налога по результатам тематической налоговой проверки налоговый орган составляет:

1) акт налоговой проверки по подтверждению достоверности суммы превышения налога, предъявленной к возврату, с учетом результатов его обжалования (при обжаловании налогоплательщиком);

2) заключение к акту налоговой проверки в случаях, предусмотренных настоящим Кодексом.

<a id="p-5"></a>5. Сумма превышения налога, подтвержденная к возврату по результатам тематической налоговой проверки, подлежит возврату в течение пятидесяти пяти рабочих дней, следующих за днем истечения срока представления декларации по налогу с указанием требования о возврате.

Сумма превышения налога на основании заключения к акту налоговой проверки подлежит возврату в течение десяти рабочих дней, следующих за днем вручения заключения к акту налоговой проверки.
