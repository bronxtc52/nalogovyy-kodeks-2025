# Статья 271. Вычет по курсовой разнице

> [!info] Особенная часть > Раздел 5. Корпоративный подоходный налог > Глава 26. Вычеты > Параграф 2. Отдельные виды вычетов
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=350) · обновлено 01.09.2024 · редакция 2026-01-01

Вычету подлежит сумма превышения величины отрицательной курсовой разницы над суммой положительной курсовой разницы.
