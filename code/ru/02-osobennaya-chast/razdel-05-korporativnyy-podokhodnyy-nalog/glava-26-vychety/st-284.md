# Статья 284. Применение преференций

> [!info] Особенная часть > Раздел 5. Корпоративный подоходный налог > Глава 26. Вычеты > Параграф 4. Инвестиционные налоговые преференции
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=365) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Применение преференций осуществляется по одному из следующих методов:

1) методу вычета после признания объекта;

2) методу вычета до признания объекта.

Выбор метода осуществляется в налоговом регистре по инвестиционным налоговым преференциям по каждому объекту преференций.

<a id="p-2"></a>2. Применение метода вычета после признания объекта заключается в отнесении на вычеты первоначальной стоимости объектов преференций

в налоговом периоде, на который приходится день признания объекта.

<a id="p-3"></a>3. Применение метода вычета до признания объекта заключается в отнесении на вычеты затрат, включаемых в первоначальную стоимость объекта, в налоговом периоде, в котором фактически произведены такие затраты.

<a id="p-4"></a>4. Налогоплательщик в течение контрольного периода осуществляет учет объектов преференций отдельно от фиксированных активов.

Объекты преференций учитываются в разрезе каждого объекта, по которому применена преференция.

<a id="p-5"></a>5. Объект преференций, по которому преференции не аннулированы, в налоговом периоде, следующем за контрольным периодом, при соответствии положениям пункта 1 статьи 275 настоящего Кодекса включается в соответствующий виду такого актива стоимостный баланс группы фиксированных активов в порядке, определенном статьями 276 и 277 настоящего Кодекса.
