# Статья 233. Плательщики

> [!info] Особенная часть > Раздел 5. Корпоративный подоходный налог > Глава 23. Общие положения
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=301) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Плательщиками корпоративного подоходного налога являются юридические лица – резиденты Республики Казахстан, а также юридические лица – нерезиденты, осуществляющие деятельность в Республике Казахстан через постоянное учреждение или получающие доходы из источников в Республике Казахстан.

<a id="p-2"></a>2. Не являются плательщиками корпоративного подоходного налога государственные учреждения.
