# Статья 235. Объекты налогообложения

> [!info] Особенная часть > Раздел 5. Корпоративный подоходный налог > Глава 23. Общие положения
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=303) · обновлено 01.09.2024 · редакция 2026-01-01

Объектами обложения корпоративным подоходным налогом являются:

1) налогооблагаемый доход;

2) доход, облагаемый у источника выплаты;

3) чистый доход юридического лица – нерезидента, осуществляющего деятельность в Республике Казахстан через постоянное учреждение;

4) облагаемый доход контролируемых иностранных компаний и постоянных учреждений контролируемых иностранных компаний.
