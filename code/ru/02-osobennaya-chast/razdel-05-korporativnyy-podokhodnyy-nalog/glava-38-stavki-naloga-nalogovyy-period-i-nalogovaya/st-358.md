# Статья 358. Налоговый период

> [!info] Особенная часть > Раздел 5. Корпоративный подоходный налог > Глава 38. Ставки налога, налоговый период и налоговая декларация
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=460) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Для корпоративного подоходного налога налоговым периодом является календарный год с 1 января по 31 декабря.

<a id="p-2"></a>2. Если юридическое лицо было создано после начала календарного года, первым налоговым периодом для него является период времени со дня создания до конца календарного года.

При этом для целей настоящей статьи днем создания юридического лица является день его государственной регистрации в регистрирующем органе.

<a id="p-3"></a>3. Если юридическое лицо было ликвидировано, реорганизовано до конца календарного года, последним налоговым периодом для него является период времени от начала года до дня завершения ликвидации, реорганизации.

<a id="p-4"></a>4. Если юридическое лицо, созданное после начала календарного года, ликвидировано, реорганизовано до конца этого же года, налоговым периодом для него является период времени со дня создания до дня завершения ликвидации, реорганизации.

<a id="p-5"></a>5. В налоговый период не включается период времени, в течение которого налогоплательщик применял исключительно специальный налоговый режим на основе упрощенной декларации.
