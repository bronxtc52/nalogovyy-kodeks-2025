# Статья 733. Сроки представления декларации для налогоплательщиков, применяющих специальный налоговый режим для крестьянских или фермерских хозяйств

> [!info] Особенная часть > Раздел 16. Специальные налоговые режимы > Глава 79. Специальный налоговый режим для крестьянских или фермерских хозяйств
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=926) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Декларация для налогоплательщиков, применяющих специальный налоговый режим для крестьянских или фермерских хозяйств, предназначена для отражения сумм исчисленных индивидуального подоходного налога (кроме удерживаемого у источника выплаты) и платы за пользование водными ресурсами поверхностных водных объектов.

<a id="p-2"></a>2. Декларация для налогоплательщиков, применяющих специальный налоговый режим для крестьянских или фермерских хозяйств, представляется не позднее 31 марта налогового периода, следующего за отчетным налоговым периодом, в соответствующие налоговые органы по месту нахождения земельного участка.
