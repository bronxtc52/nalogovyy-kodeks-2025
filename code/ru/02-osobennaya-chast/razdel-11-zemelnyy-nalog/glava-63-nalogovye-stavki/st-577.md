# Статья 577. Базовые налоговые ставки на земли населенных пунктов

> [!info] Особенная часть > Раздел 11. Земельный налог > Глава 63. Налоговые ставки
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=736) · обновлено 01.09.2024 · редакция 2026-01-01

Категория населенного пункта
