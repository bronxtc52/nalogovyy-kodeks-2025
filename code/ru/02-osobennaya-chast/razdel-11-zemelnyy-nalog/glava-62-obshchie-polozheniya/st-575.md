# Статья 575. Налоговая база

> [!info] Особенная часть > Раздел 11. Земельный налог > Глава 62. Общие положения
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=733) · обновлено 01.09.2024 · редакция 2026-01-01

Налоговой базой для определения земельного налога является площадь земельного участка и (или) земельной доли.
