# Статья 586. Налоговый период

> [!info] Особенная часть > Раздел 11. Земельный налог > Глава 65. Налоговый период и налоговая отчетность
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=747) · обновлено 01.09.2024 · редакция 2026-01-01

Налоговым периодом для исчисления земельного налога является календарный год с 1 января по 31 декабря.
