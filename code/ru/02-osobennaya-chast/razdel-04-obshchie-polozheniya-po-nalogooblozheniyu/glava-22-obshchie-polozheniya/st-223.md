# Статья 223. Юридическое лицо – резидент

> [!info] Особенная часть > Раздел 4. Общие положения по налогообложению доходов резидентов и нерезидентов > Глава 22. Общие положения
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=289) · обновлено 01.09.2024 · редакция 2026-01-01

Юридическое лицо признается резидентом в случаях:

1) создания юридического лица в соответствии с законодательством Республики Казахстан;

2) создания юридического лица в соответствии с законодательством иностранного государства, место эффективного управления (место нахождения фактического органа управления) которого находится в Республике Казахстан.

<a id="p-2"></a>2. Местом эффективного управления (местом нахождения фактического органа управления) признается место проведения собрания фактического органа управления (совета директоров или аналогичного органа), на котором осуществляются управление и (или) контроль, а также принимаются решения, необходимые для проведения предпринимательской деятельности юридического лица.
