# Статья 560. Уплата социального налога

> [!info] Особенная часть > Раздел 9. Социальный налог > Глава 57. Порядок исчисления и уплаты налога
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=707) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Уплата социального налога производится не позднее 25 числа месяца, следующего за налоговым периодом, по месту нахождения налогоплательщика.

<a id="p-2"></a>2. Уплата социального налога по объектам налогообложения, являющимся расходами структурного (территориального) подразделения, производится по месту нахождения такого структурного (территориального) подразделения.
