# Статья 661. Порядок исчисления и уплаты

> [!info] Особенная часть > Раздел 14. Платежи в бюджет > Глава 70. Платы > Параграф 7. Плата за цифровой майнинг
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=837) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Сумма платы исчисляется плательщиками платы исходя из фактических объемов электрической энергии, потребленной при осуществлении цифрового майнинга, и установленной ставки платы.

<a id="p-2"></a>2. Плательщики платы уплачивают в бюджет текущие суммы платы ежеквартально не позднее 25 числа второго месяца, следующего за отчетным кварталом.

<a id="p-3"></a>3. Сумма платы подлежит уплате в бюджет по месту нахождения налогоплательщика.
