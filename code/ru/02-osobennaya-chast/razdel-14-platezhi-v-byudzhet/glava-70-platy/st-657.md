# Статья 657. Общие положения

> [!info] Особенная часть > Раздел 14. Платежи в бюджет > Глава 70. Платы > Параграф 7. Плата за цифровой майнинг

<a id="p-1"></a>1. Плата за цифровой майнинг (далее в целях настоящего параграфа – плата) взимается за объем электрической энергии, потребленной при цифровом майнинге.
