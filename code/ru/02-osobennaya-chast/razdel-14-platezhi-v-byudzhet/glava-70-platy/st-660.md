# Статья 660. Налоговый период и налоговая декларация

> [!info] Особенная часть > Раздел 14. Платежи в бюджет > Глава 70. Платы > Параграф 7. Плата за цифровой майнинг
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=836) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Налоговым периодом для исчисления платы является квартал.

<a id="p-2"></a>2. Декларация представляется в налоговый орган по месту нахождения налогоплательщика ежеквартально не позднее 15 числа второго месяца, следующего за отчетным кварталом.
