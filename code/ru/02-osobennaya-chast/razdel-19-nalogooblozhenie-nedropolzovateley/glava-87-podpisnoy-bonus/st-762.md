# Статья 762. Особенности исчисления подписного бонуса по лицензиям на недропользование, за исключением лицензий, выдаваемых по результатам аукциона

> [!info] Особенная часть > Раздел 19. Налогообложение недропользователей > Глава 87. Подписной бонус
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=967) · обновлено 01.09.2024 · редакция 2026-01-01
