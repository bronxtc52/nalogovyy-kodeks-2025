# Статья 765. Налоговая декларация

> [!info] Особенная часть > Раздел 19. Налогообложение недропользователей > Глава 87. Подписной бонус
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=970) · обновлено 01.09.2024 · редакция 2026-01-01

Декларация по подписному бонусу представляется плательщиком подписного бонуса в налоговый орган по месту нахождения не позднее 15 числа второго месяца, следующего за налоговым периодом.
