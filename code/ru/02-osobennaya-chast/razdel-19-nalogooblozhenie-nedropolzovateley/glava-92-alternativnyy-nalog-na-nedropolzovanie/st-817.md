# Статья 817. Налоговая декларация

> [!info] Особенная часть > Раздел 19. Налогообложение недропользователей > Глава 92. Альтернативный налог на недропользование
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=1030) · обновлено 01.09.2024 · редакция 2026-01-01

Декларация по альтернативному налогу на недропользование представляется налогоплательщиком в налоговый орган по месту нахождения не позднее 31 марта года, следующего за отчетным налоговым периодом.
