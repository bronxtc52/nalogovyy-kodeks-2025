# Статья 816. Срок уплаты налога

> [!info] Особенная часть > Раздел 19. Налогообложение недропользователей > Глава 92. Альтернативный налог на недропользование
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=1029) · обновлено 01.09.2024 · редакция 2026-01-01

Альтернативный налог на недропользование подлежит уплате в бюджет по месту нахождения налогоплательщика не позднее десяти календарных дней после срока, установленного для сдачи декларации.
