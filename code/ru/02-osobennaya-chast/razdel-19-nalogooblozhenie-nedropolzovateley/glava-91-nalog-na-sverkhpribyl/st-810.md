# Статья 810. Срок уплаты налога

> [!info] Особенная часть > Раздел 19. Налогообложение недропользователей > Глава 91. Налог на сверхприбыль
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=1022) · обновлено 01.09.2024 · редакция 2026-01-01

Налог на сверхприбыль уплачивается в бюджет по месту нахождения налогоплательщика не позднее десяти календарных дней после срока, установленного для сдачи декларации.
