# Статья 801. Чистый доход для целей исчисления налога на сверхприбыль

> [!info] Особенная часть > Раздел 19. Налогообложение недропользователей > Глава 91. Налог на сверхприбыль
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=1013) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Чистый доход для целей исчисления налога на сверхприбыль определяется как разница между налогооблагаемым доходом для целей исчисления налога на сверхприбыль, определенным в соответствии со статьей 802 настоящего Кодекса, и корпоративным подоходным налогом по контракту на недропользование, исчисленным в соответствии со статьей 805 настоящего Кодекса.

<a id="p-2"></a>2. Для нерезидентов, осуществляющих деятельность по недропользованию в Республике Казахстан через постоянное учреждение, чистый доход для целей исчисления налога на сверхприбыль дополнительно уменьшается на расчетную сумму налога на чистый доход постоянного учреждения по соответствующему контракту на недропользование, исчисленного в соответствии со статьей 806 настоящего Кодекса.
