# Статья 420. Декларация по индивидуальному подоходному налогу по предпринимательской деятельности

> [!info] Особенная часть > Раздел 6 > Глава 41. Порядок исчисления, уплаты индивидуального подоходного налога и представления налоговой отчетности по доходам, подлежащим налогообложению физическим лицом самостоятельно > Параграф 5. Декларация по индивидуальному подоходному налогу по предпринимательской деятельности
> Источник: [Учет.kz](https://new.uchet.kz/tax-code?TAX_CODE=nalogovyy-kodeks-2025&ARTICLE_ID=540) · обновлено 01.09.2024 · редакция 2026-01-01

<a id="p-1"></a>1. Индивидуальные предприниматели, применяющие общеустановленный порядок налогообложения, представляют декларацию по индивидуальному подоходному налогу по предпринимательской деятельности.

<a id="p-2"></a>2. Декларация по индивидуальному подоходному налогу по предпринимательской деятельностипредставляется в налоговый орган по месту нахождения не позднее 31 марта года, следующего за отчетным налоговым периодом, за исключением ликвидационной налоговой отчетности.

<a id="p-3"></a>3. Срок представления ликвидационной декларации по индивидуальному подоходному налогу по предпринимательской деятельности при прекращении деятельности индивидуального предпринимателя установлен статьями 74 – 76 настоящего Кодекса.
