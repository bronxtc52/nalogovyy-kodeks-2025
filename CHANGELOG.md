# История изменений

Формат: версия корпуса + редакция кодекса, на которую он снят. Изменения самого кодекса
приходят отдельными коммитами и тегами `revision/<дата>`, чтобы `git diff` показывал
буквальное изменение нормы.

## v0.1.0 — 2026-08-18

Первый выпуск. Редакция кодекса **2026-01-01**, срез источника **2026-08-17**.

- 849 статей (номера 1–848, статья 419 в источнике дважды) в `code/ru/**/st-NNN.md`
  с YAML-frontmatter и якорями на каждый пункт.
- Иерархия «часть → раздел → глава → параграф» восстановлена из оглавления источника;
  файлы уровня `_razdel.md` и `_glava.md`.
- `index.md`, `llms.txt`, `manifest.json` с sha256 по каждому файлу, `datapackage.json`.
- `data/chunks.jsonl` — 3 147 чанков по пунктам статей с контекстными заголовками.
- `scripts/` — воспроизводимая сборка на стандартной библиотеке Python: корпус, чанки,
  sqlite с FTS5, эталонный набор, baseline-прогон, 15 проверок целостности.
- `eval/` — 53 размеченных вопроса и честный baseline на BM25 (без эмбеддингов).
- Даты введения в действие проставлены по статье 848, включая нормы с отложенным сроком.
- Правовой контур: MIT на код, CC0 на разметку, DISCLAIMER о неофициальности копии.
- `scripts/ask.py` — ассистент поверх корпуса: находит нормы по вопросу, собирает контекст
  и отвечает со ссылкой на статью и пункт. Без ключа работает как сухой прогон.
- `CLAUDE.md` — инструкция для coding-агента: где искать статью, как ссылаться на пункт,
  почему нельзя править Markdown руками.
- README описывает пять способов подключения к LLM и сценарии сервисов вокруг корпуса.

### Не входит в этот выпуск

Казахская версия, подзаконные акты, эмбеддинги, MCP-сервер, история редакций —
см. дорожную карту в README.
